# Ten Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the 10 reported issues: persisted ticket title/status, select-all, refresh button, an agentic preference-honoring filing pipeline, evidence manifest, background video upload, voice warm-up, tracker-presence gating, and tickets-tab reuse.

**Architecture:** Web (Next.js 16 + Supabase + Clerk + OpenAI tool-loop agent) and Chrome MV3 extension. The agent gets an MCP-shaped tracker toolset (details/create/update/get) with a verify loop; the tickets feed gets a persisted ticket snapshot with live write-back sync; the extension moves cloud upload into the offscreen document.

**Tech Stack:** TypeScript, vitest (`npm test` in `web/`), `npx tsc --noEmit`, plain-JS extension (manual verification).

Spec: `docs/superpowers/specs/2026-06-12-ten-fixes-design.md`

### Task 8: Reuse the tickets tab (issue 10)

**Files:**
- Modify: `extension/popup.js`: helper
```js
async function openTicketsTab() {
  try {
    const tabs = await chrome.tabs.query({ url: `${APP_URL}/tickets*` });
    if (tabs.length) {
      const tab = tabs[0];
      await chrome.windows.update(tab.windowId, { focused: true });
      await chrome.tabs.update(tab.id, { active: true });
      chrome.tabs.reload(tab.id);
      return;
    }
  } catch {}
  chrome.tabs.create({ url: TICKETS_URL });
}
```
used in `bcShowSentAndOpen` and the Brief Cloud button (tickets case only).
